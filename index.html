Your agents forget. You shouldn't have to.

Tawn is a memory core that runs on your own machine and sits underneath the AI tools you already use. It does not replace them. It gives them one shared memory — and keeps a record of which one changed what.

The problem

Every agent starts from nothing, every single time.

You explained the architecture to Claude Code on Monday. On Tuesday you explained it again to Cursor. On Wednesday ChatGPT suggested the approach you rejected in March, because nothing told it you had.

The models are not the bottleneck any more. The context is. Each tool keeps its own island of memory, none of them can see the others, and the work you did to get one of them up to speed is thrown away the moment you close the tab.

Where Tawn sits

Not another agent. The floor the others stand on.

Tawn is not trying to win the assistant war, and it does not want you to switch. Keep Claude Code for refactors, Cursor for edits, ChatGPT for whatever you use ChatGPT for. Tawn speaks MCP, so each of them can read the same memory — and write back into it.

The result is that the context you built once is there in all of them, and the work each of them did is visible to you afterwards.

Compiles what you already have

Notes, documents, repositories, and the session transcripts your agents already write to disk. Nothing new to maintain.

Serves every agent over MCP

Add one entry to claude.json and your tools share a memory instead of each starting from zero.

Records who did what

Git identity, then correlation against your agents' own session logs, then timing. Uncommitted work is attributed too, and every result carries its confidence.

Stays on your machine

PostgreSQL you own. It reads only the paths you grant, starting from nothing at all, and refuses to fall back to a paid cloud model silently.

Across your work

One memory, filed by the life it belongs to.

Tawn separates what it knows into domains, so asking about a deployment does not surface your reading list. It infers the domain where it can, and leaves it blank where it genuinely cannot — an honest gap beats a confident mislabel.

Recall

Search by meaning, not keywords, so you do not have to remember your own phrasing. tawn recall "what did I decide about vector storage"

A wiki it wrote itself

People, projects and tools it found in your memory, cross-linked. Opens as an Obsidian vault, because it is just markdown.

Review notes

When a work session ends, Tawn writes what changed, who changed it, and what looks worth a second look.

Every cost, attributed

One ledger across all providers. Calls it cannot price are reported as unpriced rather than quietly counted as free.

Skills that follow you

Write an instruction once; Tawn syncs it into every agent on the machine, and imports the ones they already have.

An audit log you can verify

Hash-chained. If an entry were altered or removed, verification says exactly where the chain breaks.

Getting started

Four commands, then it is yours.

You need Python 3.12 and PostgreSQL. The setup wizard handles the database, the extension, the schema and your first model — pressing Enter accepts every default.

Tawn starts able to read nothing. You decide what it sees, and tawn doctor tells you when something is wrong.

  4. Connect an agent — add to ~/.claude.json

Questions people actually ask

Does this replace Claude Code or Cursor?

No, and it is not trying to. Tawn sits underneath them. You keep whichever agent you like for whichever job; Tawn gives all of them the same memory and records what each one did.

Where does my data go?

Nowhere. It lives in a PostgreSQL database on your machine. Tawn reads only the paths you explicitly grant, and it will not send your corpus to a cloud model unless you turn that on per operation.

How can it tell which agent wrote something?

Three signals, tried in order. Git author and committer identity where a commit exists. Correlation against the session logs your coding agents already write, which catches uncommitted work. Timing heuristics last. Every answer carries its confidence, and a weak one is shown as “likely” rather than stated as fact.

Does it cost anything?

No. It is MIT licensed and works entirely offline with a local model through Ollama. Add your own provider keys if you want stronger models, and Tawn records what every call costs.

What if I am not a developer?

Today, Tawn is a command-line tool with a local web interface, and setting it up means running a few commands. If that is a barrier, the feedback box below is the right place to say so.

Is it finished?

No. It is in active development and the roadmap is public. Sharing memory with other people is not built yet, and the web interface has no authentication — which is why it binds to localhost and refuses to expose itself.

Tell us what is missing.

Tawn is early and shaped by what people say they need. If something is broken, confusing, or absent, this reaches the people building it.
