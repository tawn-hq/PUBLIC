The Tawn manual

Five parts: what it is, how to set it up, how to use it, what it can see, and where to look things up. No prior experience assumed — where a step needs a term you may not know, the term is explained where it appears and again in the glossary.

Honest about where this is. Tawn is a command-line tool with a local web interface. You will type commands into a terminal; there is no installer you double-click yet. If that is a barrier for you, say so — it is exactly the feedback that decides what gets built next.

Part one

Understand

What Tawn is

You probably use more than one AI assistant — perhaps Claude Code for refactors, Cursor for editing, ChatGPT for thinking out loud. Each keeps its own memory, and none can see the others.

So you explain the same context repeatedly. And when something in your project changed last week, nothing can tell you which assistant changed it.

Tawn is a program that runs on your own computer and fixes both. It reads the files you allow it to read, turns them into a memory searchable by meaning, and offers that memory to every assistant you use. While you work, it records what changed and who changed it.

1
It reads

Only the folders you grant. Notes, documents, code, and the session logs your assistants already write.

2
It organises

Into a memory searchable by meaning, filed by area of life, with a map of the people and projects it found.

3
It serves

Every assistant reads the same memory, so context you built once is there in all of them.

4
It records

What changed, and whether you or a specific assistant changed it.

What it is not

Not a replacement for your assistants
Keep using them. Tawn sits underneath, and is useless without them.
Not a cloud service
No account, no server of ours, nothing to sign up for. It runs on your machine.
Not something that reads everything
It starts able to read nothing at all, and only ever sees what you explicitly allow.

Part two

Set up

About twenty minutes, most of it waiting for downloads.

Before you begin

Two things Tawn cannot install for you, because they need administrator rights:

WhatWhy you need it
Python 3.12+The language Tawn is written in. Check with python3 --version.
PostgreSQL 14+
with pgvector		Where your memory lives, on your machine. pgvector is the part that makes searching by meaning possible.
New to terminals? Start here.

A terminal is a window where you type commands instead of clicking.

  • Windows — press Start, type PowerShell, Enter.
  • macOS — press ⌘ Space, type Terminal, Enter.
  • Linux — Ctrl + Alt + T on most systems.

Commands below start with $. That is the prompt your terminal already prints — type everything after it, not the $ itself.

The five steps

1

Install PostgreSQL needs sudo

Debian / Ubuntu
$ sudo apt install -y postgresql postgresql-16-pgvector
$ sudo systemctl enable --now postgresql
macOS
$ brew install postgresql@16 pgvector
$ brew services start postgresql@16

Windows: download the installer from postgresql.org. It asks you to set a password for the postgres user — write it down. Add pgvector afterwards with Stack Builder, bundled with the installer.

Install pgvector at the same time. Without it Tawn runs but search falls back to matching keywords instead of understanding meaning — the kind of quiet downgrade you would not otherwise notice.
2

Install Tawn

terminal
$ pipx install tawn
Do not have pipx?
terminal
# Debian / Ubuntu
$ sudo apt install -y pipx && pipx ensurepath

# macOS
$ brew install pipx && pipx ensurepath

# Windows (PowerShell)
$ py -m pip install --user pipx
$ py -m pipx ensurepath

Close the terminal and open a new one afterwards, so the change takes effect.

Check: tawn --help prints a list of commands.

3

Run the setup wizard

terminal
$ tawn setup

Four questions. Pressing Enter accepts every default.

Home folderCreates ~/.tawn/, where everything Tawn owns lives.
DatabaseCreates the database and switches on pgvector.
A modelOffers local models sized to your computer's memory.
Cloud keysOptional. Stored in your operating system's password manager, never in a file.

Check: during the database step you should see pgvector enabled — semantic search available.

4

Say what it may read

Tawn begins able to read nothing. That is deliberate. Open ~/.tawn/grants.yaml and list what it may see:

~/.tawn/grants.yaml
read:
  - ~/Documents/notes
  - ~/code/my-project

write:
  - ~/Documents/tawn-reviews

net: false      # may tools reach the internet
shell: false    # may tools run commands

read: is what it may look at. write: is the only place it may ever put files. Then confirm the change — Tawn keeps a fingerprint of this file and will not act on an edit it was not told about:

terminal
$ tawn grant confirm

Check: tawn grant list shows the folders you added.

5

Build the memory

terminal
$ tawn compile     # makes it searchable
$ tawn enrich      # makes it readable
$ tawn web start   # opens the interface

Compile reads your granted folders, discards noise like build output, and indexes everything by meaning. The first run takes a while; later runs only process what changed.

Enrich adds titles, summaries and the map of people and projects. You can stop it and run it again later — it resumes where it left off.

Check: open http://127.0.0.1:8787. That address is your own computer talking to itself; nobody else can reach it.

Check it worked

terminal
$ tawn doctor

Every line should read [ok]. If one does not, it names the unhappy part. This is the command to run whenever anything feels wrong.

Part three

Use

Day to day

Once the interface is running, compiling and enriching happen automatically every thirty minutes, so in practice you rarely type them again.

To…Type
Ask your memory a questiontawn recall "what did I decide about pricing"
Tell it something directlytawn note "Chose Postgres — no ops burden."
Summarise an areatawn brief work
Have a conversationtawn chat
It searches meaning, not words. Ask “what did I decide about storing data” and it finds a note saying “went with Postgres”, even though no word matches.

Connect your assistants

This is the part that makes Tawn worth having. Assistants speak a shared protocol called MCP; Tawn speaks it too. For Claude Code, open ~/.claude.json and add:

~/.claude.json
{
  "mcpServers": {
    "tawn": { "command": "tawn", "args": ["mcp"] }
  }
}

Restart the assistant. It can now search your memory, add to it, and summarise any area — the same memory every other connected assistant sees. Cursor, Gemini CLI and Codex use the same idea in their own settings file.

Tawn can also find the assistants already on your machine:

terminal
$ tawn mcp adopt

Anything it finds is added switched off. Finding something is not the same as agreeing to run it.

The parts explained

Memory
Everything Tawn has read — one card per document or conversation, not one per fragment. Opening a card reassembles the whole document.
Notes
Things you told it deliberately rather than things it gathered. Yours to edit or delete at any time.
Wiki
The people, projects and tools it found, and how they connect. Ordinary markdown, so it opens as an Obsidian vault if you use one.
Activity
What Tawn did and what it cost. Calls it cannot price are shown as unpriced rather than quietly counted as free.
Tools
What your twin can do — read files, search the web, research, draw diagrams — plus any assistant servers you connected. Each needs permission before it is offered.
Observer
Optional. Watches granted projects, records what changed and who changed it, and writes a short review when you stop. Off until you turn it on.

Part four

Control

What leaves your machine

Local models handle everything by default. Two things can send data outward, both off:

SettingWhat it sends
tawn enrich --cloudThe text of your documents, to a cloud model, to summarise.
embed_allow_cloud: trueYour entire collection, for indexing. Called out separately because that is a different kind of exposure from one message.

Tawn will not quietly fall back to a paid service. If no local model is available it stops and says so.

One thing to know. The web interface has no password. It is reachable only from your own computer, and Tawn refuses to expose it to the internet. Sharing with other people is being built, and arrives together with proper sign-in.

Where things are kept

~/.tawn/
raw/          your notes and imported sources
wiki/         the map it built
skills/       instructions you wrote
artifacts/    diagrams and briefings, every version kept
grants.yaml   what it may read and write
audit.jsonl   every access, chained
ledger.jsonl  every model call and its cost

Every file Tawn reads is written to a log chained together cryptographically — if an entry were altered or removed, checking the chain says exactly where it breaks. All of it is plain text you can read, search, back up or delete without Tawn's help. That is the point of keeping it local.

Troubleshooting

“Database is unreachable”
PostgreSQL is not running. sudo systemctl start postgresql on Linux, brew services start postgresql@16 on macOS, or the postgresql service in Windows Services.
Search results feel shallow
pgvector is probably off, so search is matching keywords. Run tawn db setup and look for the pgvector line.
Cards show filenames instead of titles
Enrichment has not reached them. Run tawn enrich, or wait for the automatic pass.
A scanned PDF comes back empty
Reading scans needs Tesseract: sudo apt install tesseract-ocr, then pipx inject tawn pytesseract Pillow pymupdf.
A change had no effect
A running server keeps the version it started with. tawn web stop && tawn web start.
Something else
Run tawn doctor first. If that does not explain it, tell us.

Glossary

Terminal
A window where you type commands instead of clicking. Also called a command line, shell, or PowerShell.
Command
A line you type into a terminal. Shown here starting with $, which your terminal already prints.
PostgreSQL
A database — software that stores information in an organised way. Runs on your machine.
pgvector
An addition to PostgreSQL that lets it compare meanings rather than exact words.
Compile
Reading your files and making them searchable. Nothing to do with programming languages here.
Enrich
A second pass adding titles, summaries and connections, so memory is pleasant to read.
Grant
Permission you give Tawn to read or write a specific folder. Without one it can do neither.
MCP
Model Context Protocol — the shared language assistants use to talk to outside tools.
Model
The AI itself. Local ones run on your machine for free; cloud ones you pay for.
Domain
An area of life memory is filed under: work, wealth, research, academic, hobby.
Audit log
A record of every file Tawn read, chained so tampering is detectable.
Ledger
A record of every AI call and what it cost.
Attribution
Working out who made a change — you, or which assistant. Marked “likely” when inferred rather than known.
